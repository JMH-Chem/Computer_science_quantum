# 현재 완성 범위와 다음 검증

현재 버전은 **v0.3, 실제 계산이 가능한 로컬 연구·학습 프로그램**이다. 기능의 존재,
작은 예제에서의 수치 검증, 실제 사용자 장비에서의 지원 확인을 구분한다.

## 처음 계획 대비

| 단계 | 현재 상태 | 남은 범위 |
| --- | --- | --- |
| 기존 프로그램 조사·수치 기준선 | 대표 프로그램 조사, PySCF 기준 입력·자원 기록, Psi4와 분자 8개 독립 비교 통과 | 조사 대상 전체나 모든 물성의 설치·실행 비교는 아님 |
| 공통 실행 기반 | 프로세스별 계산, 순차 큐, SQLite, 취소, 저장 이벤트 재접속, 실패 상태 보존 구현·검증 | 공유 서버·계정·HPC 운영은 범위 밖 |
| 분자·결정 통합 화면 | 구조 입력, 실제 수렴 그래프, 최종 상태, 기록·내보내기 구현·브라우저 검증 | 실제 사용자 관찰을 통한 사용성 검증 |
| 전문 결과 탐색 | 최적화, TDDFT·NTO, 밀도·오비탈, 결정 밴드·DOS, 조건 비교 구현 | 지원된 방법·작업 조합에 한함 |
| 학습과 자체 계산기 | 7종 조건 비교 실험, 한국어 해설, NumPy RHF 구현·검증 | 적분은 PySCF 제공. 실제 시간 동역학은 없음 |
| 설치·재현 | 의존성 잠금, 로컬 wheel, 새 Linux 가상환경 설치·실제 계산 확인 | 실제 Windows WSL2·16GB 장비 검증 미완료 |

추가로 MP2·CC·CI·CAS·NEVPT2, HF 응답·EOM-CCSD, 진동·IR·조건부 열화학을
구현했다. 상관 계산은 주로 닫힌껍질 RHF 기준 단일점이며, EOM-CCSD는 여기
에너지만 제공한다. 작은 중성 3차원 비금속 결정의 PBE 계산이 현재 재료 지원
범위다. 함수형·기저 검색 목록의 모든 조합을 검증한 것은 아니다.

금속·표면·결함·셀 최적화, 전문 평면파·PAW 엔진, GW/BSE, xTB, 실제 S₁→S₀
동역학은 아직 구현되지 않았다. 자세한 제한은 [방법론 안내](methods.md)를 따른다.

## 다음 순서

1. **독립 분자 수치 검증 — 첫 기준선 완료:** 동일 BSE 기저 정의와 핵심 전자 처리로
   Psi4와 HF·MP2·CCSD·PBE 8개 사례를 비교해 통과했다. PBE는 별도의 격자 세분
   검사도 통과했다. [실제 비교 기록](independent-validation.md)에 범위와 값을 보존했다.
2. **실제 목표 장비 검증:** Windows WSL2·16GB PC에서 설치, Windows 브라우저 접속,
   분자·결정 계산, 취소·재접속·파일 내보내기를 확인한다. Linux 결과로 대신하지 않는다.
3. **대표 사용 흐름 검토:** 물 최적화→IR, 포름알데히드 TDDFT→NTO,
   다이아몬드 수렴 비교→밴드·DOS의 세 흐름을 실제 사용자와 확인한다.
4. **다음 계산 엔진 선택:** 위 검증 이후 빠른 분자 구조 준비가 우선이면 xTB,
   재료 적용 범위가 우선이면 QE/GPAW/CP2K의 별도 어댑터를 설계한다.

현재 자료만으로 지원 완료라고 말할 수 없는 항목은 실제 WSL2, 모든 16GB PC에서의
자원 적합성, 전체 함수형·원소·기저 조합, 독립 엔진으로 확인하지 않은 물성이다.
검증 기록의 통과 숫자가 이 범위를 자동으로 넓히지는 않는다.

현재 구현과 검증 근거는 [README](../README.md), [검증 기록](validation.md),
[v0.3 개발 기록](development-v03.md), [화면 정리 기록](design-refresh.md)에 보존한다.
