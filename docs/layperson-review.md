# 일반 사용자 이해도 검토

## 검토 방법과 한계

2026-11-14(한국 시간), 현재 한국어 화면·도움말·실험 설명을 읽고 새 브라우저
문맥에서 첫 방문 흐름을 따라간 **전문가의 인지적 점검**이다. 실제 일반인을 모집한
사용성 실험이 아니며, 이해율·성공률·만족도를 측정했다고 주장하지 않는다.

검토 질문은 다음과 같다.

1. 계산화학 용어를 모르는 사람이 첫 계산을 시작할 수 있는가?
2. 설정을 바꾸기 전에 무엇이 달라지는지 설명을 찾을 수 있는가?
3. 완료된 숫자와 그래프에서 자신이 무엇을 알게 됐는지 말할 수 있는가?
4. 계산의 수렴, 방법의 근사, 실험값과의 일치를 구분할 단서가 있는가?

직접 확인한 브라우저 관찰은 `.cache/layperson-review-observations.json`,
첫 화면은 `.cache/layperson-first-768.png`에 남겼다. 제품 수정 전 관찰 기록이다.

## 수정 전 판단

검토 시작 당시 화면은 대학 일반화학이나 계산화학의 도움을 받는 학습자에게 출발점이 됐다.
과학적 제한도 비교적 명확히 표기한다. 다만 **배경 지식이 없는 일반인이 혼자
계산 조건을 고르고 결과를 해석하기에는 안내가 부족할 가능성이 크다.** 설명의
유무보다, 필요한 순간에 쉬운 설명이 먼저 나타나는지가 문제다.

첫 방문은 물 분자의 HF/STO-3G 설정이며, 학습 모드에서도 편집 가능한 기본 입력
8개, 작업 선택 8개, 방법 선택 10개가 노출된다. 1440×768 화면에서 계산 시작
버튼은 첫 화면 아래에 있다. 학습 탭에는 16개 설명이 한꺼번에 나타나고 첫 SCF
설명부터 유효 퍼텐셜·DIIS·궤도 기울기를 사용한다. 이것은 실제 관찰한 UI 구조이며,
사용자가 반드시 실패한다는 실험 결과는 아니다.

## 우선 수정할 다섯 가지

| 우선순위 | 예상되는 막힘 | 수정 방향 | 완료 확인 방법 |
| --- | --- | --- | --- |
| 1 | 처음 무엇을 눌러야 할지 모름 | 학습 모드에 짧은 첫 계산 안내와 H₂ 예제 불러오기 동작 제공. 예제를 불러오는 것과 실제 실행을 구분 | 예제 선택 후 좌표·방법이 함께 바뀌고, 계산 시작→결과 읽기 안내가 연결되는지 확인 |
| 2 | 전하·스핀·기저·함수형을 뜻을 모른 채 조작 | 해당 입력 옆에 짧은 뜻과 기본 예제에서 유지할 값 설명. 전문 설정과 입력 이름은 유지 | 전문가 기능을 잃지 않으면서 해당 입력을 보는 즉시 설명을 찾을 수 있는지 확인 |
| 3 | 녹색 수렴 완료를 과학적 정확성의 인증으로 읽음 | 완료 상태 가까이에 수렴과 정확도 차이를 간단히 표시 | 수렴만으로 실험값 일치·연구 정확도를 주장하지 않는 문장이 완료 화면에서 보이는지 확인 |
| 4 | 음수 전체 에너지·오비탈·여기 에너지를 같은 값으로 혼동 | 결과 유형별로 무엇을 계산했는지, 단위와 비교 범위를 먼저 설명 | 전체 에너지와 빛 흡수에 필요한 에너지 차이, KS 갭과 광학 갭을 구분할 수 있는 문장 확인 |
| 5 | 설명도 전문 용어여서 이해에 도움이 적음 | 핵심 개념을 쉬운 첫 문장→현재 화면에서 볼 것→한계→원문 출처 순서로 구성 | 첫 문장만 읽어도 다음 행동을 정할 수 있고 정밀한 설명·출처도 보존되는지 확인 |

전체 설정을 숨기거나 학습 모드에서 계산을 임의로 바꾸는 방식은 권하지 않는다.
같은 결과를 사용하면서 설명과 시작 순서를 개선할 수 있다. 화면의 얇은 구분선과
표 중심 구성은 유지하고, 큰 소개 카드나 반복 배너를 다시 늘리지 않는다.

## 제안 문구

아래는 검토 당시 제안한 문구다. 실제 반영한 시작·설정 안내는 다음 절에 구분했다.

- **첫 계산:** “처음이라면 수소 분자(H₂)로 시작하세요. 예제를 불러온 뒤 계산 시작을
  누르면 전자 분포를 찾아가는 과정을 볼 수 있습니다. 처음에는 전하·스핀·기저를
  바꾸지 않아도 됩니다.”
- **전하:** “0은 중성입니다. +1은 중성 분자보다 전자가 하나 적고, −1은 하나 많습니다.”
- **스핀:** “두 스핀 방향의 전자 수 차이(Nα−Nβ)입니다. 회전 속도나 다중도 값이
  아닙니다. H₂·물 기본 예제에서는 0을 사용합니다.” 홀전자 수와 항상 같다고 설명하지 않는다.
- **기저:** “전자 상태의 공간 모양을 표현하는 수학 함수들의 집합입니다. 더 큰 기저는
  표현을 풍부하게 하지만 계산량도 늘립니다. STO-3G는 원리를 보는 작은 학습용 기저입니다.”
- **함수형:** “DFT에서 전자 사이 상호작용의 일부를 근사하는 계산 규칙입니다.
  모든 분자와 물성에 가장 정확한 한 가지 함수형은 없습니다.”
- **수렴:** “수렴은 반복 계산의 변화가 설정한 기준 안으로 작아졌다는 뜻입니다.
  실험값과 얼마나 맞는지는 기저·방법·격자와 기준 자료를 따로 확인해야 합니다.”
- **전체 에너지:** “현재 원자 배치와 계산 방법으로 구한 계 전체의 에너지입니다.
  단위 Eh는 하트리입니다. 숫자가 더 음수라는 이유만으로 다른 분자나 다른 방법이
  더 정확하다고 판단하지 않습니다.”
- **흡수:** “전자 상태를 바꾸는 데 필요한 에너지 차이입니다. 여기서는 원자의 위치를
  고정한 수직 여기 에너지를 계산합니다. 실제 흡수 띠의 최대값이나 형광 에너지와
  바로 같지는 않습니다.”
- **IR:** “원자들이 평형 구조 근처에서 작게 진동한다고 가정한 계산입니다.
  실제 분자의 진동은 완전한 조화 운동이 아니므로 실험의 기본 진동수와 차이가 날
  수 있습니다. 선폭 조절은 그림의 모양을 바꾸며 계산 정확도를 높이지 않습니다.”

## 이번에 반영한 시작·설정 안내

`Settings.tsx`·`App.tsx`·`styles.css`에 다음을 반영했다.

- 학습 모드 상단에 H₂ 예제 불러오기와 3단계 시작 안내를 추가했다. 예제 불러오기는
  입력을 준비하고 새 작업 화면으로 전환하며 계산 요청을 보내지 않는다.
- 기존 계산 시작 버튼을 학습 모드에서는 설정 상단에, 전문가 모드에서는 기존
  설정 하단에 배치했다. 화면에 하나만 존재하며 같은 입력 수집·실행 함수를 사용한다.
- 전하·스핀·기저·함수형 입력에 쉬운 설명을 연결했다. 입력 이름은 유지하고
  `aria-describedby`로 설명과 해당 입력을 연결했다.
- 학습 결과에 Eh의 의미와 수렴·실험 정확도 구분을 추가했다. 전문가 전환은
  계산 입력이나 저장된 결과를 변경하지 않는다.

기존 어두운 카드나 큰 소개 영역을 추가하지 않고 설정 패널의 짧은 안내로 구성했다.
`frontend/e2e/learning.spec.ts`는 실제 H₂ 계산을 사용해 예제 준비 중 자동 실행이
없는지, 1440×768 첫 화면에서 계산 시작 버튼이 보이는지, 모드 전환이 같은 계산
결과를 보존하는지 확인하도록 추가했다. 최종 TypeScript·Vite 빌드 후 실제 Chromium에서 이 흐름을 실행해 통과했다.

## 개선 후 실제 화면 확인

실제 H₂ 계산을 포함한 새 사용자 시나리오가 **1개, 8.4초**에 통과했다.
이후 최종 브라우저 전체 19개도 281.68초에 통과했다. 같은 H₂ 시나리오가
포함되므로 앞의 1개와 중복 합산하지 않는다.

- 1440×768 첫 화면에서 계산 시작 버튼은 위쪽 400.31px, 아래쪽 439.81px에
  위치한다. 수정 전 약 934px에서 첫 화면 안으로 이동했다.
- 예제 불러오기에서는 계산 요청이 없고, 계산 시작 후 실제 결과는
  **−1.116759307507584 Eh**였다. 전문가 모드 전환 후 입력·결과가 동일했다.
- 폭 390px 화면에서 가로 넘침이 없었다. 다만 모바일에서는 설정 뒤의 결과까지
  스크롤이 길다. 작은 화면의 탐색성은 다음 사용자 관찰에서 확인할 과제다.
- 브라우저 콘솔 오류와 페이지 예외가 없었다.
- 과거 EOM·TDA/TDDFT 결과에는 재계산 안내가 표시되며, 안내를 보는 것만으로
  저장된 입력·결과를 변경하거나 새 계산을 실행하지 않는다. 이 두 안내는
  읽기 전용 테스트 자료로 표시를 검사했으며 실제 수치 검증과 구분한다.

[개선된 첫 화면](images/learning-first-v031.png)을 보존했다.
원본 관찰은 `.cache/literature-learning-visual.json`에 있다.
이 확인은 화면 조작과 설명의 존재를 검증하며, 사람이 개념을 이해했다는 증거는 아니다.

## 유지해야 할 장점

- SCF 반복과 구조 최적화 단계를 실제 시간과 구분한다.
- 오비탈 색상이 전하가 아니라 위상임을 설명한다.
- S₁→S₀ 애니메이션에 교육용 모식도 표시가 있고, 계산하지 않은 수명·방출 에너지를
  계산 결과처럼 제시하지 않는다.
- 미수렴 결과를 성공값으로 채우지 않으며, 비교가 불가능한 조건은 별도로 표시한다.
- 학습 실험에서 조건 하나씩 바꾸고 “아직 모르겠어요”를 선택할 수 있다.

## 실제 사용자 확인은 별도로 필요하다

제품 개선 후 일반화학 배경이 없는 사용자와 일반화학 수강자를 구분해 다음 과제를
관찰하는 것이 적절하다. 이 단계는 이번 전문가 점검으로 대신 완료하지 않는다.

1. 도움 없이 H₂ 예제를 불러와 계산하고, 완료된 에너지의 단위를 찾아 설명하기.
2. 그래프의 가로축이 실제 시간인지 판단하고 근거를 화면에서 찾기.
3. 기저 비교에서 수렴과 정확도의 차이를 자신의 말로 설명하기.
4. 흡수 스펙트럼과 IR 그림이 서로 어떤 에너지 변화를 나타내는지 구분하기.
5. “수렴했으니 논문값과 정확히 같다”는 주장에 필요한 추가 확인을 말하기.

도움 요청 지점, 오해한 문장, 과제 완료 여부를 기록하고 그 결과로 안내를 다시
수정해야 한다. 현재 검토만으로 “일반인이 충분히 이해한다”고 확정하지 않는다.
