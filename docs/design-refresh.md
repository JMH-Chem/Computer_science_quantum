# 화면 정리: 계산 결과를 먼저 읽는 작업 공간

## 진단

기존 화면은 짙은 청록 배경, 민트·보라색 강조, 영문 장식 소제목, 반복되는 둥근
카드와 설명 배너가 많았다. 결과를 보기 전에 비슷한 안내를 여러 번 읽어야 했고,
계산 도구에 필요한 표·그래프보다 장식이 강하게 보였다.

## 적용한 규칙

| 항목 | 변경 |
| --- | --- |
| 색상 | 밝은 바탕, 먹색 글자, 파랑 강조. 두 번째 데이터 계열은 갈색으로 구분 |
| 작업 도구 | 52px 헤더, 270px 설정 영역, 작은 사각 버튼과 얇은 구분선 |
| 글자 | 한국어 중심의 간결한 제목과 기본 시스템 글꼴. 영문 장식 소제목 제거 |
| 정보 순서 | 전체 에너지·상태 → 구조·SCF → 최근 반복 표 → 상세 결과 |
| 설명 | 반복되는 해설과 제한 사항은 펼침 영역에 보존. 오류·미수렴 진단은 바로 표시 |
| 학습 실험 | 조건표와 실제 결과 그래프·표를 중심으로 배치. 큰 단계 카드를 간결한 진행 행으로 변경 |
| 수치 표시 | 표의 숫자와 단위 정렬, 실제 SCF 기록 선택, 읽을 수 있는 그래프 대비 |

계산 엔진과 저장 데이터는 변경하지 않았다. 기존 구조·SCF·IR·DOS·모드 표시와
다운로드 동작을 유지했다. 오비탈의 두 색상은 여전히 파동함수 위상이며 전하 색상이 아니다.

실제 브라우저 검사에서 실험 그래프의 초기 resize가 작은 패딩 높이를 읽는 문제를
확인했다. 그래프의 요청 높이를 컨테이너에 명시하고, SVG가 읽을 수 있는 높이로
표시되는지 회귀 검사에 추가했다. 좌표 편집창에는 자동 줄바꿈을 없애 한 원자가
여러 줄로 보이지 않게 했다.

검증 결과:

- TypeScript 검사와 Vite 프로덕션 빌드 통과.
- 기존 브라우저 시나리오 18개 중 최초 실행에서 17개 통과. 설명이 펼침 영역으로
  이동해 실패한 1개는 테스트에서 해당 영역을 여는 동작을 반영했다.
- 수정 후 해당 실패 시나리오, 실제 물 분자의 3개 기저 비교, H₂ 계산·재접속·내보내기를
  다시 실행해 3개 모두 통과했다. 실험 그래프 SVG 높이 검사도 포함한다.
- 1440px 데스크톱과 390px 모바일 화면 확인. 브라우저 오류 없음, 모바일 문서 폭
  390px로 가로 넘침 없음. 실험 그래프 높이 270px 확인.
- 변경 파일의 Prettier 검사와 `git diff --check` 통과.

수치 엔진의 Python 검사는 이번 디자인 변경에서 다시 실행하지 않았다.
