# 방법론, 기저, 함수형과 결과 해석

이 문서는 계산 방법의 선택 이유와 첫 구현의 범위를 설명한다. 기능표의 지원은 모든 원소·기저·함수형·작업 조합이 검증되었다는 뜻이 아니다. 실행 화면의 조합별 상태와 개별 작업의 수렴 결과를 확인해야 한다.

## 방법론 지도

| 방법 | 계산하는 것과 핵심 근사 | 첫 구현 | 확장 시 검증할 항목 |
| --- | --- | --- | --- |
| RHF/UHF | 단일 Slater determinant와 평균장. RHF는 닫힌껍질, UHF는 α/β 궤도를 분리한다. | 분자 바닥상태 | 스핀 오염, 불안정 해, 결합 해리와 강한 상관의 한계 |
| RKS/UKS DFT | 밀도와 교환·상관 함수형을 이용하는 바닥상태 방법. | 분자 및 제한된 주기계 PBE | 함수형·격자·기저 수렴, 비국소 상관·분산 등의 실제 지원 |
| TDHF | HF 기준의 선형응답 여기 상태. | 조사 범위; 독립 작업으로 제공하지 않음 | 에너지·전이 세기·불안정성 |
| TDA / LR-TDDFT | 바닥상태 주변 선형응답에서 여기 에너지와 전이 성질을 얻는다. | 분자 닫힌껍질 singlet | 응답 수렴, 전하이동·Rydberg·이중여기·다중참조 특성 |
| MP2 | HF 기준의 2차 섭동 상관 에너지. | 후속 | 작은 분자 교차 검증, 기저 수렴, 작은 에너지 분모 문제 |
| CCSD / CCSD(T) / EOM-CC | 결합 클러스터 바닥상태 상관과 여기 상태. | 후속 | 참조 상태 적합성, residual 수렴, 크기·메모리 비용 |
| CASSCF / CASPT2 / NEVPT2 | 활성공간에서 정적 상관을 다루고 필요하면 동적 상관을 보완한다. | 후속 | 활성공간·상태 평균·root 추적, 방법별 제약 |
| DMRG | 큰 활성공간 문제의 근사 수치 풀이기. | 조사 범위 | bond dimension 수렴, 외부 solver와 버전·라이선스 |
| GW | 전자 추가·제거에 관련된 준입자 에너지. | 후속 | 시작점, 비점유 밴드·유전 응답·주파수 수렴 |
| BSE | 전자–정공 상호작용을 포함한 광학 응답. | 후속 | GW 등 기반 자료와 일관성, k점·밴드 수렴 |
| xTB 등 반경험적 방법 | 파라미터화된 빠른 근사 전자구조. | 후속 엔진 후보 | 원소·화학 환경 적용 범위, 정확도 한계 |
| Born–Oppenheimer MD | 각 핵 배치에서 전자 상태를 계산하며 핵을 시간 적분한다. | 후속 | 에너지 보존·시간 간격·온도 제어 |
| 실시간 TDDFT | 시간 의존 전자 상태를 명시적으로 전파한다. | 후속 | 시간 간격·외부장·게이지·에너지 보존 |
| 비단열 동역학 | 핵과 여러 전자 상태, 상태 간 결합을 함께 고려한다. | 별도 후속 설계 | 초기조건·앙상블·결합·전이 알고리즘·관측량 |

기저 함수 수를 K라 할 때 전통적 구현의 MP2, CCSD, CCSD(T)는 각각 대략 K⁵, K⁶, K⁷ 수준의 대표 비용을 가진다. 실제 시간은 적분 처리, density fitting, 국소화, 병렬화, 구조와 구현에 크게 달라진다. 이 차수를 실행 시간 예측값으로 사용하지 않는다.

## 함수형 선택

교환·상관 함수형은 모든 문제에 대한 정확도 순위로 나열할 수 없다. 목표 물성, 분자·재료 종류, 기준 데이터, 기저와 수치 조건을 함께 고려한다.

| 계열 | 예 | 선택 시 확인할 점 |
| --- | --- | --- |
| LDA | SVWN 계열 | 국소 밀도 의존. 입문·방법 비교에는 유용하지만 대상 물성의 검증이 필요하다. |
| GGA | PBE | 밀도 기울기를 포함한다. 첫 주기계 기본값으로 사용하지만 밴드갭이나 분산 상호작용을 자동으로 정확히 재현하지 않는다. |
| meta-GGA | TPSS, SCAN 계열 | 운동에너지 밀도나 다른 변수 의존. 엔진의 미분·응답·기울기 지원을 확인한다. |
| Hybrid | PBE0, B3LYP | 정확 교환의 일부를 포함한다. 계산 비용과 장거리 전하이동·밴드갭 해석에 주의한다. |
| Range-separated hybrid | CAM-B3LYP 등 | 거리별 교환 처리가 다르다. 장거리 여기에서 유용할 수 있지만 파라미터와 작업별 지원을 확인한다. |
| Double hybrid | B2PLYP 등 | 섭동 상관 등의 추가 계산이 필요할 수 있다. 함수형 이름이 파싱된다는 이유만으로 완전한 방법이 구현되었다고 표시하지 않는다. |

첫 분자 프리셋은 PBE·PBE0·B3LYP다. 전체 검색 목록은 설치된 PySCF/Libxc가 알려주는 항목에서 만든다. **목록에 존재하는 것, 바닥상태 계산이 가능한 것, 기울기·TDDFT까지 검증된 것은 각각 다른 상태**다. 사용한 정확한 함수형 식과 라이브러리 버전을 결과에 남긴다.

분산 보정, 용매 모형, 상대론, spin–orbit coupling 등은 함수형 이름만으로 자동 포함된다고 가정하지 않는다. 첫 구현에서 명시적으로 제공하지 않는 보정은 결과에 들어 있지 않다.

## 분자 기저와 ECP

- **STO-3G:** 작은 최소 기저. 알고리즘 학습과 빠른 작동 확인에 적합하다. 연구 정확도의 기본 추천으로 취급하지 않는다.
- **def2-SVP / def2-TZVP:** 기저 크기 증가와 polarization의 영향을 비교하는 초기 선택지다. 원소·물성에 따라 더 큰 기저나 diffuse 함수가 필요할 수 있다.
- **Diffuse 함수:** 음이온, 약하게 묶인 전자, Rydberg 여기에서 중요할 수 있다. 선형종속과 수렴 문제도 확인한다.
- **ECP:** 일부 핵심 전자를 유효 퍼텐셜로 바꾼다. 기저와 대응되는 ECP를 선택하고 실제 전자 수·스핀·출처를 기록한다. ECP 계산을 동일 이름의 all-electron 결과와 섞어 비교하지 않는다.
- **원소별 기저:** 원소마다 다른 기저를 사용할 수 있지만 전체 원소가 빠짐없이 정의되어야 한다. 미지원 원소를 다른 기저로 자동 치환하지 않는다.

[Basis Set Exchange](https://www.basissetexchange.org/)는 기저 정의, 원소 범위, 버전과 참고문헌을 제공한다. 기저 이름뿐 아니라 실제 사용한 정의를 보존해야 향후 이름·버전 차이를 추적할 수 있다.

## 주기계의 기저·가상퍼텐셜·k점·격자

첫 구현의 PySCF PBC는 Gaussian 궤도 기저다. GTH-SZV/GTH-DZVP와 GTH-PBE 가상퍼텐셜을 함께 사용한다. 첫 대상은 중성 3D 비금속 결정이며 금속 스미어링·부분 점유 계산은 지원 범위 밖이다.

출력 밀도는 계산에 포함한 가전자의 밀도다. 가상퍼텐셜이 대체한 핵심 전자까지 포함하는 all-electron 밀도가 아니다. 밀도 적분 비교에서도 해당 가전자 수를 기준으로 한다.

서로 다른 수치 조절 항목은 별도로 수렴시킨다.

1. **궤도 기저:** 파동함수의 표현 범위. SZV→DZVP 변화는 FFT 격자를 키우는 것과 다르다.
2. **SCF k점 격자:** Brillouin zone 적분의 정확도. Γ점 하나는 빠른 예제이며 일반적인 수렴 기준이 아니다.
3. **실공간/FFT 격자:** 밀도와 퍼텐셜 등의 수치 표현. 너무 작은 격자는 심각한 오차나 불안정성을 일으킬 수 있다.
4. **밴드 경로:** 수렴한 밀도에 대해 표시용 k점 경로에서 에너지를 구한다. 경로점을 늘리는 것이 SCF k점 적분을 수렴시키지는 않는다.

밴드 에너지는 표시 기준을 명시한다. 가전자대 최대값(VBM)을 0 eV로 옮긴 그림은 절대 진공준위 기준이 아니다. 선택한 경로의 간격은 전 Brillouin zone에서 완전히 수렴한 간접 밴드갭이라고 보장할 수 없다. KS gap과 광학 gap도 다르다.

## 그래프와 색상을 읽는 법

- **SCF 에너지:** 반복 알고리즘의 수치 결과. 상승·진동·일시 정체를 숨기지 않는다.
- **최적화 에너지:** 핵 배치 변화에 따른 값. 각 단계의 좌표와 연결해 본다.
- **전자밀도:** 공간에서 전자가 분포하는 양. 등가면 값을 바꾸면 보이는 경계가 달라지지만 계산 자체는 바뀌지 않는다.
- **분자 오비탈:** 단전자 함수의 모양. 두 색은 보통 함수의 양·음 위상이며 양전하·음전하가 아니다.
- **NTO:** 전이의 hole/particle 성격. 가중치와 정의를 함께 읽는다. 전자의 실제 이동 궤적이 아니다.
- **흡수 스펙트럼:** 계산한 여기 에너지·oscillator strength의 stick 값에 표시용 broadening을 더한 그림. Gaussian/Lorentzian 폭은 별도의 표시 설정이다.
- **상태도:** 서로 다른 전체 전자 상태의 에너지 차이를 보여준다. 분자 오비탈 에너지 사다리와 같지 않다.
- **S1→S0 모식도:** 계산되지 않은 시간·수명·분기율을 의미하지 않는 교육용 설명이다.

## 기본 수렴 비교 연습

H₂O의 PBE 단일점에서 기저를 STO-3G→def2-SVP→def2-TZVP로 바꾸고, 같은 기저에서 수치 격자를 늘려 결과를 비교한다. 기저와 격자를 동시에 바꾸면 무엇 때문에 달라졌는지 분리하기 어렵다.

다이아몬드에서는 동일 구조·기저·가상퍼텐셜에서 Γ점과 2×2×2 k점 결과를 비교하고, 격자를 더 촘촘하게 했을 때의 변화를 확인한다. 서로 다른 기저에서 전체 에너지가 비슷하다고 모든 물성이 수렴한 것은 아니다. 목표 물성별 허용오차를 먼저 정한다.

실행된 수치 결과가 없으면 이 예제는 학습 절차이며 수렴을 보증하는 표가 아니다. 실제 실행 기록은 [검증 기록](validation.md)에 남긴다.
