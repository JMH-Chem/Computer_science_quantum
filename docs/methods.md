# 방법론, 기저, 함수형과 결과 해석

이 문서는 계산 방법의 선택 이유와 v0.3의 구현 범위를 설명한다. 기능표의 지원은 모든 원소·기저·함수형·작업 조합이 검증되었다는 뜻이 아니다. 실행 화면의 조합별 상태와 개별 작업의 수렴 결과를 확인해야 한다. 실제 검사와 남은 환경 검증은 [검증 기록](validation.md)을 기준으로 한다.

## 방법론 지도

| 방법 | 계산하는 것과 핵심 근사 | 현재 지원 | 해석과 지원 경계 |
| --- | --- | --- | --- |
| RHF/UHF | 단일 Slater determinant와 평균장. RHF는 닫힌껍질, UHF는 α/β 궤도를 분리한다. | 분자 바닥상태 | 스핀 오염, 불안정 해, 결합 해리와 강한 상관의 한계 |
| RKS/UKS DFT | 밀도와 교환·상관 함수형을 이용하는 바닥상태 방법. | 분자 및 제한된 주기계 PBE | 함수형·격자·기저 수렴, 비국소 상관·분산 등의 실제 지원 |
| TDHF / HF-TDA | HF 기준의 선형응답; HF-TDA는 CIS에 대응한다. | 분자 닫힌껍질 singlet, 여기 에너지·전이 세기·NTO | 참조 상태와 응답의 불안정성, triplet 미지원 |

| MP2 | RHF 기준의 2차 섭동 상관 에너지. | 닫힌껍질 분자 단일점, 동결 점유 궤도 수 지정 | 작은 분모·참조 상태·기저 의존성. MP2는 변분 상한이 아님 |

| EOM-EE-CCSD | 수렴한 CCSD 기준의 전자 수 보존 여기 상태. | 닫힌껍질 singlet 수직 여기 에너지와 잔차 | 오른쪽 고유벡터만 계산. 전이 세기·흡수 스펙트럼·NTO는 미계산 |
| CISD | HF 기준 단일·이중 들뜸 configuration interaction. | 닫힌껍질 단일점, 동결 점유 궤도 수 지정 | 잘린 CI는 일반적으로 size-consistent하지 않음 |
| FCI | 지정한 유한 기저 안의 전체 configuration interaction. | 작은 닫힌껍질 분자, 자원 제한 적용 | 유한 기저의 정확해이며 완전 기저·상대론 등을 포함한 정확해는 아님 |
| CASCI / CASSCF | 선택한 활성 공간의 CI; CASSCF는 궤도도 최적화한다. | 닫힌껍질 단일점, 활성 전자·궤도 수 지정 | 연속된 정준 RHF 궤도로 초기 공간 선택. 상태 평균·임의 궤도 선택·root 추적 미지원 |
| NEVPT2 | 활성공간 참조에 2차 동적 상관을 더한다. | singlet CASCI 기준 strongly contracted NEVPT2 | CASSCF 최적화 참조가 아님. 활성 궤도 최대 8개와 메모리 제한 |
| 조화 진동 / IR / RRHO | 입력 구조의 Hessian과 국소 진동, 쌍극자 미분, 이상 기체 열화학. | ECP 없는 닫힌껍질 RHF/RKS, HF 또는 PBE/PBE0/B3LYP | 2~30원자, 비조화성·용액·고체 열화학 미포함 |
| DMRG | 큰 활성공간 문제의 근사 수치 풀이기. | 조사 범위 | bond dimension 수렴, 외부 solver와 버전·라이선스 |
| GW | 전자 추가·제거에 관련된 준입자 에너지. | 후속 | 시작점, 비점유 밴드·유전 응답·주파수 수렴 |
| BSE | 전자–정공 상호작용을 포함한 광학 응답. | 후속 | GW 등 기반 자료와 일관성, k점·밴드 수렴 |
| xTB 등 반경험적 방법 | 파라미터화된 빠른 근사 전자구조. | 후속 엔진 후보 | 원소·화학 환경 적용 범위, 정확도 한계 |
| Born–Oppenheimer MD | 각 핵 배치에서 전자 상태를 계산하며 핵을 시간 적분한다. | 후속 | 에너지 보존·시간 간격·온도 제어 |
| 실시간 TDDFT | 시간 의존 전자 상태를 명시적으로 전파한다. | 후속 | 시간 간격·외부장·게이지·에너지 보존 |
| 비단열 동역학 | 핵과 여러 전자 상태, 상태 간 결합을 함께 고려한다. | 별도 후속 설계 | 초기조건·앙상블·결합·전이 알고리즘·관측량 |

기저 함수 수를 K라 할 때 전통적 구현의 MP2, CCSD, CCSD(T)는 각각 대략 K⁵, K⁶, K⁷ 수준의 대표 비용을 가진다. 실제 시간은 적분 처리, density fitting, 국소화, 병렬화, 구조와 구현에 크게 달라진다. 이 차수를 실행 시간 예측값으로 사용하지 않는다.

## 상관 방법과 활성 공간

상관 계산의 전체 에너지, RHF 참조 에너지, 두 값의 차이를 각각 저장한다. SCF 반복의 에너지는 RHF 참조이며, 최종 상관 에너지를 그 반복값으로 대체하지 않는다. MP2는 비반복 계산이고, CCSD·CI·CASSCF는 해당 풀이기의 수렴도 확인한다. CCSD가 미수렴이면 (T)나 EOM을 실행한 것처럼 표시하지 않는다.

**상관 방법 결과에서 제공하는 궤도·CUBE 밀도·쌍극자·원자 전하는 RHF 참조의 값이다.** CASSCF나 NEVPT2를 선택했어도 이 자료를 해당 방법의 상관 밀도라고 해석하지 않는다. 일부 CI/CAS 결과의 natural occupation은 별도 진단 자료이며, 제공된 공간과 정의를 함께 기록한다.

`frozen_orbitals`는 MP2·CCSD·CCSD(T)·CISD의 낮은 에너지 점유 궤도 수다. CASCI·CASSCF·NEVPT2에서는 `active_electrons`, `active_orbitals`로 비활성 핵심 궤도 수를 산정하고, 그 다음의 연속된 정준 RHF 궤도를 초기 활성 공간으로 선택한다. 실제 선택한 1부터 시작하는 궤도 번호를 결과에 남긴다. CASSCF는 이 초기 궤도를 최적화하지만 화학적으로 적합한 활성 공간을 자동 발견하는 기능은 아니다.

FCI는 전체 분자 궤도 최대 12개, CAS는 활성 궤도 최대 12개이며 CI determinant 수는 100,000 이하로 제한한다. NEVPT2는 네 입자 밀도행렬 비용 때문에 활성 궤도를 최대 8개로 제한한다. 조밀 적분·배열의 사전 메모리 추정이 예산의 60%를 넘으면 실행을 거부한다. 이 검사는 운영체제 수준의 강제 RAM 제한이나 실제 최대 메모리 보장이 아니다.

## 분자 물성과 조화 진동

수렴한 SCF 참조에서 Mulliken·Löwdin 원자 전하, 전하 합, 쌍극자와 비제한 계산의 스핀 진단을 제공한다. 원자 전하는 밀도를 나누는 정의와 기저에 의존하며 유일한 관측량으로 취급하지 않는다. 서로 다른 population analysis 값이 다르다는 이유만으로 어느 계산이 틀렸다고 판단하지 않는다.

진동 작업은 해석적 RHF/RKS Hessian에서 병진·회전을 제거하고 질량 정규화 모드를 계산한다. 모드의 주파수는 cm⁻¹, 허수 모드는 음수로 표시한다. 화면의 모드 움직임은 임의 진폭의 모식도이며 실제 온도·시간 궤적이 아니다. 평균 동위원소 질량과 주파수 보정 계수 1을 사용한다.

동일한 방법·기저·수치 조건으로 구조를 먼저 최적화한 뒤 진동수를 계산하는 것이 기본 흐름이다. 최대 Cartesian 기울기가 `4.5e-4 Eh/bohr`를 넘으면 비정지 구조로 표시하고 RRHO 열화학을 제공하지 않는다. 모드가 모두 양수일 때만 ZPE를 합산하며, 0 이하 모드를 임의로 버려 정상 최소점처럼 처리하지 않는다. 정지점 조건과 모든 양의 모드를 만족하면 지정 온도·압력의 이상 기체 RRHO 내부 에너지·엔탈피·Gibbs 에너지·엔트로피·열용량을 제공한다. 낮은 진동수의 내부 회전과 비조화성, 용액·고체 효과는 포함하지 않는다.

선택적인 IR 세기는 각 원자의 세 방향에 대해 `±0.005 bohr`로 변위한 총 쌍극자의 중앙 유한 차분을 사용한다. 추가 SCF가 `6N`개 필요하며 모든 변위의 수렴을 확인한다. 하나라도 실패하면 IR 세기를 만들지 않고 부분 기록과 진동 결과를 보존한다. 세기의 단위는 km/mol이며 변위·격자·SCF 오차의 수렴은 별도로 검토해야 한다.

## 함수형 선택

교환·상관 함수형은 모든 문제에 대한 정확도 순위로 나열할 수 없다. 목표 물성, 분자·재료 종류, 기준 데이터, 기저와 수치 조건을 함께 고려한다.

| 계열 | 예 | 선택 시 확인할 점 |
| --- | --- | --- |
| LDA | SVWN 계열 | 국소 밀도 의존. 입문·방법 비교에는 유용하지만 대상 물성의 검증이 필요하다. |
| GGA | PBE | 밀도 기울기를 포함한다. 첫 주기계 기본값으로 사용하지만 밴드갭이나 분산 상호작용을 자동으로 정확히 재현하지 않는다. |
| meta-GGA | TPSS, SCAN 계열 | 운동에너지 밀도나 다른 변수 의존. 엔진의 미분·응답·기울기 지원을 확인한다. |
| Hybrid | PBE0, B3LYP | 정확 교환의 일부를 포함한다. 계산 비용과 장거리 전하이동·밴드갭 해석에 주의한다. |
| Range-separated hybrid | CAM-B3LYP 등 | 거리별 교환 처리가 다르다. 장거리 여기에서 유용할 수 있지만 파라미터와 작업별 지원을 확인한다. |
| Double hybrid | B2PLYP 등 | 섭동 상관 등의 추가 계산이 필요할 수 있다. 함수형 이름이 파싱된다는 이유만으로 완전한 방법이 구현되었다고 표시하지 않는다. |

첫 분자 프리셋은 PBE·PBE0·B3LYP다. 전체 검색 목록은 설치된 PySCF/Libxc가 알려주는 항목에서 만든다. **목록에 존재하는 것, 바닥상태 계산이 가능한 것, 기울기·TDDFT까지 검증된 것은 각각 다른 상태**다. 사용한 정확한 함수형 식과 라이브러리 버전을 결과에 남긴다.

분산 보정, 용매 모형, 상대론, spin–orbit coupling 등은 함수형 이름만으로 자동 포함된다고 가정하지 않는다. 첫 구현에서 명시적으로 제공하지 않는 보정은 결과에 들어 있지 않다.

## 분자 기저와 ECP

- **STO-3G:** 작은 최소 기저. 알고리즘 학습과 빠른 작동 확인에 적합하다. 연구 정확도의 기본 추천으로 취급하지 않는다.
- **def2-SVP / def2-TZVP:** 기저 크기 증가와 polarization의 영향을 비교하는 초기 선택지다. 원소·물성에 따라 더 큰 기저나 diffuse 함수가 필요할 수 있다.
- **Diffuse 함수:** 음이온, 약하게 묶인 전자, Rydberg 여기에서 중요할 수 있다. 선형종속과 수렴 문제도 확인한다.
- **ECP:** 일부 핵심 전자를 유효 퍼텐셜로 바꾼다. 기저와 대응되는 ECP를 선택하고 실제 전자 수·스핀·출처를 기록한다. ECP 계산을 동일 이름의 all-electron 결과와 섞어 비교하지 않는다.
- **원소별 기저:** 원소마다 다른 기저를 사용할 수 있지만 전체 원소가 빠짐없이 정의되어야 한다. 미지원 원소를 다른 기저로 자동 치환하지 않는다.

[Basis Set Exchange](https://www.basissetexchange.org/)는 기저 정의, 원소 범위, 버전과 참고문헌을 제공한다. 기저 이름뿐 아니라 실제 사용한 정의를 보존해야 향후 이름·버전 차이를 추적할 수 있다.

## 주기계의 기저·가상퍼텐셜·k점·격자

현재 PySCF PBC는 Gaussian 궤도 기저다. GTH-SZV/GTH-DZVP와 GTH-PBE 가상퍼텐셜을 함께 사용한다. 대상은 중성 3D 비금속 결정이며 금속 스미어링·부분 점유 계산은 지원 범위 밖이다.

출력 밀도는 계산에 포함한 가전자의 밀도다. 가상퍼텐셜이 대체한 핵심 전자까지 포함하는 all-electron 밀도가 아니다. 밀도 적분 비교에서도 해당 가전자 수를 기준으로 한다.

서로 다른 수치 조절 항목은 별도로 수렴시킨다.

1. **궤도 기저:** 파동함수의 표현 범위. SZV→DZVP 변화는 FFT 격자를 키우는 것과 다르다.
2. **SCF k점 격자:** Brillouin zone 적분의 정확도. Γ점 하나는 빠른 예제이며 일반적인 수렴 기준이 아니다.
3. **실공간/FFT 격자:** 밀도와 퍼텐셜 등의 수치 표현. 너무 작은 격자는 심각한 오차나 불안정성을 일으킬 수 있다.
4. **밴드 경로:** 수렴한 밀도에 대해 표시용 k점 경로에서 에너지를 구한다. 경로점을 늘리는 것이 SCF k점 적분을 수렴시키지는 않는다.

밴드 에너지는 표시 기준을 명시한다. 가전자대 최대값(VBM)을 0 eV로 옮긴 그림은 절대 진공준위 기준이 아니다. 선택한 경로의 간격은 전 Brillouin zone에서 완전히 수렴한 간접 밴드갭이라고 보장할 수 없다. KS gap과 광학 gap도 다르다.

DOS는 균일한 **SCF k점 격자**의 상태에 동일한 k점 가중치와 스핀 축퇴도 2를 적용하고, 표준편차 0.1 eV의 Gaussian으로 넓힌 값이다. 고대칭 경로는 Brillouin zone 적분 가중치가 없으므로 DOS에 섞지 않는다. 전체 DOS 적분은 유한 기저의 상태 수, 점유수로 가중한 DOS의 전체 적분은 가전자 수와 비교한다. Gaussian 꼬리가 갭으로 번지는 것은 실제 갭 내부 상태나 온도 점유를 뜻하지 않는다.

직접·간접 갭과 VBM·CBM 위치는 계산한 SCF 격자 및 요청한 밴드 경로의 표본 안에서만 찾는다. 단위격자 부피·질량 밀도·원자당 에너지도 제공하며, 질량 밀도에는 가상퍼텐셜의 가전자 질량이 아닌 ASE의 표준 원자 질량을 사용한다.

## 그래프와 색상을 읽는 법

- **SCF 에너지:** 반복 알고리즘의 수치 결과. 상승·진동·일시 정체를 숨기지 않는다.
- **최적화 에너지:** 핵 배치 변화에 따른 값. 각 단계의 좌표와 연결해 본다.
- **전자밀도:** 공간에서 전자가 분포하는 양. 등가면 값을 바꾸면 보이는 경계가 달라지지만 계산 자체는 바뀌지 않는다.
- **분자 오비탈:** 단전자 함수의 모양. 두 색은 보통 함수의 양·음 위상이며 양전하·음전하가 아니다.
- **NTO:** 전이의 hole/particle 성격. 가중치와 정의를 함께 읽는다. 전자의 실제 이동 궤적이 아니다.
- **흡수 스펙트럼:** 계산한 여기 에너지·oscillator strength의 stick 값에 표시용 broadening을 더한 그림. Gaussian/Lorentzian 폭은 별도의 표시 설정이다.
- **상태도:** 서로 다른 전체 전자 상태의 에너지 차이를 보여준다. 분자 오비탈 에너지 사다리와 같지 않다.
- **S1→S0 모식도:** 계산되지 않은 시간·수명·분기율을 의미하지 않는 교육용 설명이다.

## 학습 실험 7종

| 실험 | 바꾸는 조건 | 고정 조건과 주의점 |
| --- | --- | --- |
| 물의 기저 | STO-3G → def2-SVP → def2-TZVP | PBE·격자 3·구조 고정; 서로 중첩된 한 기저 계열이 아님 |
| 물의 적분 격자 | Level 1 → 3 → 5 | PBE/def2-SVP 고정; 에너지 단조 변화 보장 없음 |
| 물의 함수형 | PBE → PBE0 → B3LYP | def2-SVP·격자 3 고정; 낮은 전체 에너지로 함수형 정확도 순위를 매기지 않음 |
| H₂ 결합 거리 | 0.50, 0.74, 1.00, 1.50, 2.00 Å | RHF/STO-3G; 표본 곡선이며 최적화·시간 동역학이 아님, 장거리 RHF 해리 한계 |
| 다이아몬드 k점 | Γ → 2³ → 3³ | PBE/GTH-SZV/GTH-PBE·FFT 15³ 고정; 거친 격자의 학습 예제 |
| 다이아몬드 FFT 격자 | 15³ → 21³ → 27³ | 같은 방법·기저·Γ점 고정; k점 수렴은 확인하지 않음 |
| 물의 전자 상관 | RHF → MP2 → CCSD | STO-3G·구조 고정; 상관 에너지와 참조 물성을 구분 |

각 실험은 생성 시 전체 입력과 비교 순서를 저장한다. 실패한 중간 계산을 건너뛰어 ΔE를 연결하거나, 비수렴 값을 0으로 채우지 않는다. 결정은 단위격자 전체 에너지와 원자당 에너지를 구분한다. 실행 시간과 최대 RSS는 해당 컴퓨터의 한 번의 측정이며 일반적인 성능 순위가 아니다.

이 목록을 모두 실행해도 기저·격자·k점 또는 관심 물성의 수렴이 자동으로 증명되지는 않는다. 목표 물성별 허용오차를 먼저 정해야 한다. 실제 실행 기록은 [검증 기록](validation.md)에 남긴다.
