# 독립 엔진 비교: PySCF 앱과 Psi4

2026-11-14(한국 시간), Linux x86-64에서 **8개 분자 사례와 PBE 격자 세분 검사가
모두 사전에 정한 허용오차를 통과**했다. 앱은 PySCF 2.15.0, 별도 비교 환경은
Psi4 1.11이다. 화면이나 앱 계산 엔진을 교체하지 않고 선택적 검증 도구를 추가했다.

차이는 표시된 반올림 값이 아니라 전체 정밀도의 원본 값으로 계산했다. 상관 계산은
RHF 기준 에너지와 상관 보정도 각각 비교해 통과했다. “동결 1”은 최저 점유 공간
오비탈 하나를 상관 계산에서 제외한다는 뜻이며, 핵심 전자를 가상퍼텐셜로 대체하지 않는다.

PBE의 격자 1/2는 앱의 level 5/6, Psi4의 99×590 / 175×974 unpruned 격자다.
같은 격자가 아니다. 두 격자 사이 변화는 앱 **4.72e-8 Eh**, Psi4 **1.36e-8 Eh**로,
별도로 정한 2e-6 Eh 이내였다. 이 구조·기저에서의 결과이며 다른 물성의 격자 수렴을
자동으로 보증하지 않는다.

## 일치시킨 조건과 실행 기록

- 기저 이름만 맞추지 않고 같은 BSE 정의를 두 엔진에 전달했다. 앱의 실제 기저
  자료가 공통 정의와 같은지도 확인했다.
- All-electron, spherical AO, restricted 참조, conventional HF·상관 계산으로
  맞췄다. density fitting을 사용하지 않았다.
- 앱의 Å→Bohr 변환값으로 만든 동일 핵 좌표를 Psi4에 전달했다. 좌표, 핵 반발
  에너지, 전자 수, 기저 함수 수, 동결 점유 오비탈 수를 검사했다.
- 실제 앱 모듈 경로, 의존성 버전, Python 소스 해시, 실행기 시작·종료 해시를
  보존했다. 최종 실행 중 소스가 바뀌지 않았음을 확인했다.
- 누락·미수렴·시간 초과·비유한 값은 통과로 처리하지 않는다. PBE 격자 하나만
  선택하면 전체 상태는 `incomplete`이며 성공 종료하지 않는다.

앱의 시간은 기저 해석·물성·파일 저장을 포함하지만 Psi4의 시간은 `energy()`
구간이다. 측정 범위가 달라 속도 비교로 해석하지 않는다. 최대 RSS는 인터프리터와
라이브러리도 포함한다. 이 환경은 실제 16GB PC가 아니다.

## 재현과 검사

[설치·실행 안내](../validation/README.md), [전체 정밀도 입력·결과](cross-engine-results.json),
[실행기](../scripts/cross_engine.py), [회귀 검사](../tests/test_cross_engine.py)를 함께 보존한다.
독립 환경의 101개 패키지는 URL·빌드·체크섬을 잠갔다. 잠금 파일의 별도 설치 계획
생성도 통과했다. 파일만 준비하고 설치했다고 표현한 것이 아니라, 실제 별도 Psi4
환경에서 위 계산들을 실행했다.

검증 도구의 실패 처리·입력 변조·조건 불일치·출처 변경·부분 DFT 판정을 검사하는
**30개 테스트가 1.09초에 통과**했다. Ruff와 diff 검사도 통과했다. 이어서 최종
실행기로 8개 실제 비교를 다시 실행해 전부 통과했다. 이번 변경은 제품 엔진·화면을
수정하지 않았으므로 기존 Python·브라우저 전체 검사를 다시 실행하지 않았다.

## 이 결과가 확인하지 않은 것

실험값의 정확도, TDDFT·NTO·IR 등의 독립 물성 비교, 주기계의 다른 엔진 비교,
다른 원소·전하·스핀·ECP·활성 공간, 실제 Windows WSL2·16GB 장비는 이 검사에
포함되지 않는다. 전체 완성 범위와 다음 우선순위는 [현재 상태](release-readiness.md)에
구분했다. 외부 게시나 공개 배포는 수행하지 않았다.
